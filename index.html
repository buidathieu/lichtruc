Thiết lập Google Sheets API

Dán đường link Apps Script của bạn vào đây để ứng dụng có thể đọc/ghi dữ liệu.

Hướng dẫn tạo API (3 phút):

  1. Tạo một file Google Sheets mới.
  2. Chọn menu Tiện ích mở rộng > Apps Script.
  3. Xóa code cũ, dán đoạn code dưới đây vào và lưu lại.
  4. Bấm Triển khai (Deploy) > Triển khai mới.
  5. Chọn Ứng dụng Web. Quyền truy cập: Bất kỳ ai.
  6. Copy URL được cấp và dán vào ô bên trên.
